## 📊 1. 북극성 지표 (North Star Metric, NSM)

### 1.1 제안 지표

**"월간 활성 조직 수 (Monthly Active Organizations, MAO)"**

- **정의**: 한 달 동안 최소 1건 이상의 체크리스트를 제출한 조직(회사/현장)의 총 개수
- **측정 기준**: 
  - 조직 내 최소 1명 이상의 기술인이 체크리스트를 제출
  - 제출된 체크리스트가 최소 1건 이상 승인 완료 상태에 도달

### 1.2 선택 이유

#### 비즈니스 성공의 핵심 신호
1. **B2B SaaS 특성 반영**: 개인 사용자가 아닌 조직 단위의 채택이 진짜 성공 지표
2. **네트워크 효과**: 한 조직이 활성화되면 내부 사용자(기술인/감독자/안전관리자)가 자연스럽게 증가
3. **수익 연결성**: 조직 단위 과금 모델과 직접 연결 (조직당 월 구독료 또는 사용자 수 기반)
4. **지속 가능성**: 단순 방문이 아닌 실제 워크플로우 사용을 의미하므로 재구매/갱신 가능성 높음

#### 빠른 호흡의 비즈니스 액션
- **주간 단위로도 추적 가능**: 주간 활성 조직 수(WAO)로 단기 모니터링
- **명확한 액션 유도**: "이번 주에 몇 개 조직을 활성화시킬 것인가?"라는 구체적 목표 설정 가능
- **조직 단위 확장 전략**: 한 조직 내에서 역할별 사용자 확장(기술인 → 감독자 → 안전관리자)이 자연스럽게 발생

### 1.3 선행 지표 (Input Metrics) - 3가지

우리가 **완전히 제어 가능한** 행위의 총량으로 측정되는 지표입니다.

#### 📌 선행 지표 1: 주간 신규 조직 온보딩 수 (Weekly New Organization Onboarding)

- **정의**: 매주 새로 가입하고 최소 1명의 사용자 계정을 생성한 조직 수
- **측정 방법**: 
  - 조직 가입일 기준으로 주 단위 집계
  - 조직 내 첫 사용자 계정 생성 완료 시점 기준
- **목표 설정 예시**: 
  - 1주차: 5개 조직
  - 2주차: 8개 조직
  - 4주차: 15개 조직
- **액션 아이템**:
  - 랜딩페이지 CTA 클릭 → 데모 신청 → 온보딩 완료까지의 전환율 최적화
  - 원청(S2) 기업을 통한 하청(S1) 조직 추천 프로그램
  - 정부 보조금 연계 마케팅 (안전관리 디지털화 지원 사업)

#### 📌 선행 지표 2: 조직당 주간 체크리스트 제출 건수 (Weekly Checklist Submissions per Organization)

- **정의**: 활성 조직당 주간 평균 체크리스트 제출 건수
- **측정 방법**: 
  - 주간 총 제출 건수 ÷ 활성 조직 수
  - 활성 조직 = 해당 주에 최소 1건 이상 제출한 조직
- **목표 설정 예시**: 
  - 초기: 조직당 주 2건
  - 성숙기: 조직당 주 5건 이상
- **액션 아이템**:
  - 기술인 대상 모바일 UX 최적화 (체크리스트 작성 시간 단축)
  - 게이미피케이션 요소 강화 (퀘스트, 보상 시스템)
  - 감독자 승인 속도 개선 (알림, "내 할 일" 우선순위 표시)
  - 템플릿 자동 로딩 속도 개선 (1초 이내 목표)

#### 📌 선행 지표 3: 조직당 주간 활성 역할 수 (Weekly Active Roles per Organization)

- **정의**: 한 조직 내에서 주간에 실제 활동한 역할(기술인/감독자/안전관리자)의 평균 개수
- **측정 방법**: 
  - 조직별로 주간에 활동한 역할 종류 수를 집계
  - 활동 기준: 로그인 + 최소 1건 이상의 액션(작성/승인/조회 등)
  - 전체 조직의 평균값 계산
- **목표 설정 예시**: 
  - 초기: 조직당 1.5개 역할 (기술인만 사용)
  - 성숙기: 조직당 2.5개 역할 이상 (기술인 + 감독자 + 안전관리자)
- **액션 아이템**:
  - 감독자용 "검토할 체크리스트" 대시보드 강화
  - 안전관리자용 "위험현황 모니터링" 대시보드 가시성 향상
  - 역할별 맞춤형 온보딩 튜토리얼 제공
  - 조직 내 역할 간 협업 유도 (예: "감독자 승인 대기 중" 알림)

## 🎯 2. AARRR 퍼널 분석

### 2.1 Acquisition (획득) - 고객이 우리를 처음 발견하는 방법

#### 핵심 채널 전략

##### 🎯 채널 1: B2B2B 추천 프로그램 (최우선)
- **대상**: 원청 기업(S2 규제 대응군) → 하청 협력사(S1 위험 외주형 현장군)
- **메커니즘**:
  - 원청 기업의 안전팀장(이팀장 페르소나)이 하청 협력사에 도입 권장
  - 원청 기업이 "안전관리 디지털화 의무화" 정책 수립 시 우리 솔루션 추천
- **구체적 실행**:
  - 대형 건설사/제조사 안전팀장 대상 세미나/웨비나 개최
  - "중대재해처벌법 대응 가이드" 무료 제공 (우리 솔루션 소개 포함)
  - 원청 기업 계약 시 하청 협력사 온보딩 지원 프로그램 제공

##### 🎯 채널 2: 정부 보조금 연계 마케팅
- **대상**: 중소 협력사(S1) - 정부 지원 사업 참여 기업
- **메커니즘**:
  - "안전관리 디지털화 지원 사업" 연계
  - "스마트 안전관리 시스템 도입 지원금" 활용
- **구체적 실행**:
  - 중소벤처기업진흥공단, 한국산업안전보건공단(KOSHA) 협력
  - 보조금 신청 시 우리 솔루션을 추천 솔루션으로 등록
  - 보조금 신청 가이드 제공 (우리 솔루션 도입 시)

##### 🎯 채널 3: 검색 엔진 최적화 (SEO)
- **대상**: 구글 검색을 통한 자발적 발견
- **핵심 키워드**:
  - 1차: "중대재해처벌법 대응", "현장 안전관리 시스템", "법정 자율점검표 전산화"
  - 2차: "건설현장 안전관리 솔루션", "AI 위험도 분석", "안전관리 자동화"
- **구체적 실행**:
  - 랜딩페이지 SEO 최적화 (이미 완료)
  - 블로그 콘텐츠 마케팅: "중대재해처벌법 대응 체크리스트", "안전관리 디지털화 가이드"
  - KOSHA, 건설안전협회 등 관련 기관 사이트에 백링크 확보

##### 🎯 채널 4: 업계 전시회/세미나
- **대상**: 건설안전협회, 산업안전보건협회 등 업계 행사 참석자
- **구체적 실행**:
  - 부스 운영 및 데모 시연
  - "게이미피케이션으로 안전관리 참여율 3배 증가" 사례 발표
  - 현장 소장/안전 담당자 명함 수집 및 후속 연락

#### Acquisition 성공 기준
- **목표**: 월간 신규 조직 가입 수 20개 이상
- **전환율 목표**: 
  - 랜딩페이지 방문 → 데모 신청: 3%
  - 데모 신청 → 실제 가입: 30%

### 2.2 Activation (활성화) - "아하!" 모먼트

#### 핵심 활성화 행동 정의

**"첫 체크리스트 제출 완료"**

- **이유**: 
  - 서비스의 핵심 가치(법정 체크리스트 전산화)를 직접 경험
  - 워크플로우의 시작점 (제출 → 승인 → 조치)
  - 조직 내 다른 역할(감독자)과의 첫 연결점 생성

#### 활성화 여정 최적화

##### 🎯 단계 1: 온보딩 (가입 후 즉시)
- **목표**: 가입 후 24시간 이내 첫 체크리스트 작성 시작
- **액션**:
  - 환영 이메일 + "5분 튜토리얼" 링크 제공
  - 대시보드에 "첫 체크리스트 작성하기" 큰 버튼 배치
  - 샘플 체크리스트 템플릿 미리보기 제공

##### 🎯 단계 2: 첫 체크리스트 작성 (작성 시작 → 제출)
- **목표**: 작성 시작 후 10분 이내 제출 완료
- **액션**:
  - 작업유형 선택 → 템플릿 자동 로딩 (1초 이내)
  - 모바일 최적화 UI (큰 버튼, 간단한 네/아니요 선택)
  - 진행률 표시 (예: "3/10 완료")
  - 사진 업로드 간소화 (드래그 앤 드롭, 즉시 업로드)

##### 🎯 단계 3: 첫 승인 피드백 (제출 → 승인 확인)
- **목표**: 제출 후 48시간 이내 감독자 승인 완료
- **액션**:
  - 감독자에게 즉시 알림 ("검토할 체크리스트 1건")
  - 기술인 대시보드에 "승인 대기 중" 상태 표시
  - 승인 완료 시 "축하합니다! 첫 체크리스트가 승인되었습니다" 메시지

#### Activation 성공 기준
- **목표**: 가입 조직의 70% 이상이 가입 후 7일 이내 첫 체크리스트 제출
- **현재 벤치마크**: 
  - 가입 후 24시간 이내 첫 작성 시작: 40%
  - 가입 후 7일 이내 첫 제출 완료: 60% (목표: 70%)

### 2.3 Retention (유지) - 고객이 다시 돌아오게 만드는 요소

#### 핵심 재방문 트리거

##### 🎯 트리거 1: 역할별 "내 할 일" 대시보드
- **기술인**: 
  - "승인 대기 중인 체크리스트" 알림
  - "반려된 체크리스트 수정 필요" 알림
  - "오늘의 안전 퀘스트" (게이미피케이션)
- **감독자**: 
  - "검토할 체크리스트 N건" 배지
  - "위험 항목 포함 체크리스트 우선 표시"
  - "승인 지연 알림" (48시간 미승인 시)
- **안전관리자**: 
  - "우선 확인 필요" 위험현황 리스트
  - "AI 위험도=위험" 사진 자동 알림
  - "미조치 건수" 대시보드

##### 🎯 트리거 2: 주기적 워크플로우 (자연스러운 재방문)
- **일일 루틴**: 
  - 기술인: 매일 작업 전 체크리스트 작성 (사다리/고소작업대/밀폐공간)
  - 감독자: 매일 오전 "검토할 체크리스트" 확인
- **주간 루틴**: 
  - 안전관리자: 주간 위험현황 리포트 확인
  - 조직 단위: 주간 안전 통계 대시보드

##### 🎯 트리거 3: 게이미피케이션 요소
- **퀘스트 시스템**: 
  - 일일 퀘스트: "오늘 체크리스트 1건 제출하기" (+50 XP)
  - 주간 퀘스트: "5일 연속 체크리스트 제출" (+200 XP)
  - 월간 퀘스트: "무사고 30일 달성" (+1000 XP)
- **레벨업 & 보상**: 
  - 레벨업 시 새로운 아바타 아이템 해금
  - 조직 내 랭킹 시스템 (안전 점수 경쟁)

##### 🎯 트리거 4: 이메일/알림 (외부 재방문 유도)
- **주간 리포트 이메일**: 
  - "이번 주 안전 활동 요약" (제출 건수, 승인률, 위험도 분석)
  - "다음 주 목표" 제시
- **중요 이벤트 알림**: 
  - 체크리스트 승인/반려 결과 (기술인)
  - 새로운 위험 건 발견 (안전관리자)

#### Retention 성공 기준
- **목표**: 
  - 주간 재방문율: 60% 이상 (주간에 최소 1회 로그인한 활성 조직)
  - 월간 재방문율: 80% 이상
- **이탈 방지**: 
  - 30일 미사용 조직에 "재활성화" 이메일 발송
  - "무료 컨설팅" 제공 (사용법 재교육)

### 2.4 Revenue (수익) - 비즈니스 모델이 작동하는 지점

#### 수익 모델 제안

##### 🎯 모델 1: 조직 단위 월 구독료 (SaaS)
- **기본 플랜**: 
  - 조직당 월 50만원 (최대 10명 사용자)
  - 추가 사용자: 인당 월 5만원
- **프리미엄 플랜**: 
  - 조직당 월 100만원 (무제한 사용자 + AI 분석 고급 기능)
  - 통합 대시보드, 커스텀 리포트, API 연동

##### 🎯 모델 2: 사용량 기반 (Pay-as-you-go)
- **체크리스트 제출 건수 기반**: 
  - 기본: 월 100건까지 무료
  - 추가: 건당 1,000원
- **AI 분석 건수 기반**: 
  - 기본: 월 50건까지 무료
  - 추가: 건당 2,000원

##### 🎯 모델 3: 하이브리드 (추천)
- **기본 구독료 + 사용량 초과분**: 
  - 기본: 조직당 월 30만원 (월 50건 체크리스트 + 20건 AI 분석 포함)
  - 초과분: 체크리스트 건당 500원, AI 분석 건당 1,500원

#### Revenue 발생 시점

##### 💰 첫 수익 발생: 무료 체험 → 유료 전환
- **무료 체험 기간**: 14일 (또는 월 20건까지 무료)
- **전환 트리거**: 
  - 체험 기간 종료 전 자동 갱신 안내
  - "무제한 사용을 위해 유료 플랜으로 전환하세요" CTA
- **목표 전환율**: 체험 조직의 30% 이상이 유료 전환

##### 💰 반복 수익: 월간 구독 갱신
- **갱신률 목표**: 90% 이상 (월간 구독 갱신)
- **갱신 실패 방지**: 
  - 갱신 7일 전 이메일 알림
  - 갱신 실패 시 "할인 쿠폰" 제공 (20% 할인)

##### 💰 확장 수익: 업그레이드 (기본 → 프리미엄)
- **업그레이드 트리거**: 
  - 사용량 초과 (월 50건 이상 사용)
  - AI 분석 고급 기능 필요
- **목표**: 기본 플랜 사용자의 20% 이상이 프리미엄으로 업그레이드

#### Revenue 성공 기준
- **목표**: 
  - 월간 재발생 수익(MRR): 3개월 내 1,000만원 달성
  - 고객 생애 가치(LTV): 120만원 이상 (월 30만원 × 12개월 × 70% 갱신률)
  - 고객 획득 비용(CAC): 30만원 이하 (LTV/CAC = 4:1 이상)

### 2.5 Referral (추천) - 자발적 바이럴 발생

#### 바이럴 트리거 설계

##### 🎯 트리거 1: 조직 내 역할 확장 (내부 바이럴)
- **메커니즘**: 
  - 기술인이 체크리스트 제출 → 감독자에게 자동 알림
  - 감독자가 승인/반려 → 안전관리자에게 위험 건 자동 전달
  - 한 역할의 사용이 다른 역할의 참여를 자연스럽게 유도
- **실행**: 
  - "동료 초대하기" 기능 (역할별 초대 링크)
  - 조직 내 첫 감독자 가입 시 보너스 (예: 무료 사용자 1명 추가)

##### 🎯 트리거 2: 업계 네트워크 효과 (외부 바이럴)
- **메커니즘**: 
  - 원청 기업(S2)이 하청 협력사(S1)에 추천
  - 같은 현장 내 다른 협력사가 성공 사례를 보고 따라함
- **실행**: 
  - "추천 프로그램": 기존 고객이 새 조직을 추천하면 양쪽 모두 1개월 무료
  - 성공 사례 공유: "OO 건설사, 체크리스트 작성 시간 50% 단축" 케이스 스터디

##### 🎯 트리거 3: 게이미피케이션 경쟁 요소
- **메커니즘**: 
  - 조직 간 안전 점수 랭킹 (공개 또는 비공개 옵션)
  - "우리 현장이 가장 안전합니다" 배지/인증서 발급
- **실행**: 
  - 월간 "안전 우수 현장" 선정 및 시상
  - 랭킹 공유 기능 (소셜 미디어, 현장 게시판)

##### 🎯 트리거 4: 증빙/보고서 자동 생성 (간접 추천)
- **메커니즘**: 
  - 감사/점검 시 "안전관리 이력 리포트" 자동 생성
  - 다른 기업/기관에 리포트를 제출할 때 우리 솔루션 로고 포함
- **실행**: 
  - 리포트 하단에 "이 리포트는 '안전의 길'로 생성되었습니다" 표기
  - 리포트 공유 시 우리 랜딩페이지 링크 포함

#### Referral 성공 기준
- **목표**: 
  - 추천률(Viral Coefficient): 0.3 이상 (1명이 평균 0.3명을 데려옴)
  - 추천을 통한 신규 가입 비율: 전체 신규 가입의 30% 이상
- **측정 방법**: 
  - 가입 시 "어디서 알게 되셨나요?" 설문
  - 추천 코드 추적 (URL 파라미터, 쿠키)
